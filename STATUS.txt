🚀 PRÊT À DÉMARRER

ÉTAPE 1 : Installer les prérequis
  □ Java 21 JDK
  □ Maven 3.8+
  □ MySQL 8.0+ en cours d'exécution

ÉTAPE 2 : Créer la base de données
  mysql -u root -p < H:\Documents\GitHub\CY-J2EE-SB\conception\JeeDb.sql

ÉTAPE 3 : Configurer application.properties
  spring.datasource.url=jdbc:mysql://localhost:3306/JeeDb
  spring.datasource.username=root
  spring.datasource.password=

ÉTAPE 4 : Démarrer l'application
  Windows : run.bat
  Linux   : ./run.sh
  Autre   : mvn clean spring-boot:run

ÉTAPE 5 : Accéder à l'application
  URL : http://localhost:8080
  Username : admin
  Password : admin
